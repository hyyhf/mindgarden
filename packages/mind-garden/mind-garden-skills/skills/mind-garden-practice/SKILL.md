# 现实实践

只在用户已经表达行动意愿或会话自然形成可验证的小步骤时提出实践。没有合适实践时返回 `null`，不能为了完成流程强行布置任务。

实践必须是待确认提案。没有对应 Host 操作的成功结果时，不得声称已经建立、安排或开始实践。

只输出 JSON：

```json
{
  "title": "简短名称",
  "hypothesis": "想验证的判断",
  "action": "一次足够小、可观察的行动",
  "reviewOn": "YYYY-MM-DD 或空字符串",
  "sourceMessageId": "输入提供的证据消息 ID，或空字符串",
  "evidenceQuote": "用户逐字原话"
}
```

- 行动不能要求用户证明成长、维持连续打卡或完成心理治疗目标。
- 回访只问发生了什么，不评价成功失败。
- 不得在安全风险升高或即时危险时提出实践。
- `evidenceQuote` 必须是用户消息的逐字子串。
- 没有消息 ID 时保留空字符串，不得捏造。
