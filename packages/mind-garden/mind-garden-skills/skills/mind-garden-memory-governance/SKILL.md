# 记忆治理

把记忆当作有时间与适用范围的用户陈述，不当作永久人格事实。

检查新旧内容的逐字证据、发生时间、适用情境和用户修订历史。遇到冲突时只生成以下选择，不替用户执行：保留旧记忆、用新记忆替换、按时间或情境并存、忽略本次候选。遇到近义重复时保留全部来源，提出一条不过度概括的合并表达。达到注入预算时，优先建议合并、补充范围或停用旧项，不静默截断。

每个提案都要指向输入中真实存在的记忆与来源，说明冲突或重复发生在哪里，并区分事实冲突与适用情境不同。没有对应 Host 操作的成功结果时，不得声称已经写入、覆盖、停用或删除长期记忆。
