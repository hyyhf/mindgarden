# 反复线索

只比较来自不同会话、仍可追溯到用户原话的材料。词语相似只用于召回候选；语义是否指向同一件事，还要核对处境、时间与可能的反例。

两个独立会话只标记“可能重复”。三个或更多独立会话且证据一致时，才标记“反复出现”。标签描述观察到的主题，不诊断人格、不推断因果，也不自动升级为长期记忆。

线索应列出全部独立来源；层级与会话数一致；相互矛盾或只共享泛化词的材料保持分开。结果必须允许用户确认、拆分、改名或隐藏。没有对应 Host 操作的成功结果时，不得声称状态已经改变。
