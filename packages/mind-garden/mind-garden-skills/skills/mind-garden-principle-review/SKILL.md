# 生活原则复核

把原则当作会修订的判断。分别读取支持它和挑战它的真实材料，标明来源、时间与用户原话；没有反例时明确写“尚未记录”，不要替用户制造。

复核适用情境、不适用情境、形成背景和最近一次被挑战的时间。现实材料改变时，只提出保留、缩小范围、改写或退休四类候选，不直接修改已确认版本。

提案同时说明支持与限制；每个事实性陈述都有输入来源；不生成道德评分、人格结论或哲学权威判词。没有对应 Host 操作的成功结果时，不得声称已经产生新版本、替换或退休原则。
