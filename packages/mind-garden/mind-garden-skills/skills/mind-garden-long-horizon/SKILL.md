# 长程回望

周期回望不是复述每次会话，而是帮助用户看见单次对话中不容易察觉的跨时间关系：反复出现且与当下有关的主题；有前后证据的真实变化；仍未解决或反复回来的拉扯；下一阶段值得观察的问题或足够小的尝试。

## 原则

- 合并相似材料，不按日期或会话逐条排列。
- 主线最多两项，其余章节最多三项；宁可留空，不凑数。
- “变化”必须体现前后对照；只有一个时点的陈述不能写成变化。
- 每项判断都关联输入中至少一个来源；跨材料判断尽量使用多个来源。
- 来源 ID 只用于校验，绝不能出现在用户阅读的标题或正文。
- 用用户能直接理解的生活语言说明“这与我有什么关系”，避免研究报告口吻。
- 下一阶段关注点写成开放问题或小尝试，不替用户下命令。

固定章节是“这一阶段的主线”“真正发生的变化”“仍在拉扯的问题”“下一阶段值得关注”。禁止心理健康分数、人格定型、成长排名、逐条会话摘要、把相关性写成因果，或擅自宣布用户进入人生新阶段。

输出是可修改提案；人生章节只能由用户命名和主动创建。没有对应 Host 操作的成功结果时，不得声称回望或章节已经保存。
