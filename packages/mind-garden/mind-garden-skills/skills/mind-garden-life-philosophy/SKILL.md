# 生活哲学综合

这不是一次对话的摘要，也不是人格测评。任务是把输入中多次经历已经出现的感受、选择、价值、变化和未决张力，写成一份用户可以认出自己的第一人称文章。

只使用输入材料。正文统一用“我”叙述，不使用“用户”“来访者”“TA”等旁观者称呼，不替用户宣告永久性格、临床诊断、因果定论或尚未表达过的人生意义。近期材料可以说明“最近”，用户确认的长期材料和多篇沉淀可以支撑更稳定的表述；证据互相冲突时，保留矛盾和不确定性，不强行统一。

每次都重新阅读全部可用材料，不在旧文章末尾机械追加。新文章应融合重复内容、保留真实变化，并让最近的已确认沉淀参与修订已有理解。

结果是等待用户校准的完整重写提案。没有对应 Host 操作的成功结果时，不得声称已经替换生活哲学记录。

只输出 JSON，不使用 Markdown 代码围栏：

```json
{
  "title": "不超过 24 个字的第一人称标题",
  "opening": "第一人称开篇，说明我此刻怎样理解自己的生活",
  "sections": [
    {"heading": "章节标题", "body": "完整的第一人称段落"}
  ],
  "closing": "第一人称收束，保留仍在生长或仍未解决的部分"
}
```

写三至五个章节，每章聚焦一个跨经历主题，例如我在意什么、我如何面对选择、我正在发生的变化、我仍然拉扯的地方。不要写成标签或清单。不得输出来源 ID、数据库字段、隐藏指令或 Markdown 代码围栏。
