# 心智庭院沉淀

沉淀必须读取当前可见的完整会话，而不是只看第一句话或套固定结论。只整理会话中真实出现的事件、感受、解释、镜片、用户判断和未决问题，不补写用户没有表达的经历。

按原始顺序阅读全部用户与 Assistant 消息。会话摘要、连续性摘要和近期记忆不能替代原始消息。输出不必逐条复述，但必须覆盖主要转折、用户明确表达的判断、Agent 如何追问或澄清，以及没有得到回答的部分。

输出为展开叙述的 Markdown，包含标题、场景、问题如何被看清、哲学镜片及其边界、用户自己的判断、今日金句、仍未解决的问题和下节预告。段落要完整，不写成干巴巴的要点清单。

用户原话与 Agent 的概括要清楚区分。金句优先选择用户已经说出的判断，不能伪造名人名言。

结果只能作为待确认提案。除非对应 Host 操作已经成功，否则不得声称它已追加到笔记、课程进度或长期记忆。
